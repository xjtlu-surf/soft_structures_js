🚀 测试指南
如何测试新的笔刷功能：
  1. 启动应用：cd frontend && npm run dev
  2. 进入 Patient Entry：查看左侧工具栏
  3. 验证 Pencil 删除：
    • 确认工具栏中没有 Pencil 工具
    • 工具栏现在只有 5 个工具
  4. 测试 Brush 粗细调节：
    • 将鼠标悬停在 Brush 工具上
    • 观察右侧出现粗细调节器
    • 拖动滑动条调节粗细（2-32px）
    • 观察数值实时更新
    • 测试绘画功能，验证粗细变化
  5. 测试交互逻辑：
    • 悬停在 Brush 上显示调节器
    • 将鼠标移动到调节器上
    • 移开鼠标，观察延迟隐藏效果
